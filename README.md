# ☕ Specialized Coffee Roastery and Cafe Management System

A Java-based desktop application designed to streamline the operations of a specialized coffee roastery and cafe. Developed as part of the CSE215 Lab project, this system demonstrates core Object-Oriented Programming (OOP) concepts.

## 📖 Project Description

This system helps a cafe owner efficiently manage daily operations, from taking orders to generating final invoices. The user interface is built using **Java Swing**, providing a smooth desktop experience.

## ✨ Key Features

- **Product Management:** Add, update, and manage coffee products and roastery items.
- **Order Processing:** Take customer orders efficiently.
- **Billing System:** Automatically calculate bills based on ordered items.
- **Loyalty Discounts:** Apply special discounts for returning/loyal customers.
- **Invoicing:** Generate and print customer invoices.
- **Data Persistence:** Store invoice data locally in a text file for record-keeping.

## 🛠️ Technologies Used

- **Language:** Java
- **GUI Framework:** Java Swing
- **Data Storage:** File I/O (Text Files)
- **Paradigm:** Object-Oriented Programming (OOP)
